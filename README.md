# Salama Travel
موقع سلامة ترافيل باستخدام HTML وCSS وJavaScript.

## الملفات
- `index.html`: الصفحة الرئيسية والكود الخاص بتغيير اللغة.
- `css/style.css`: تنسيق وتصميم الموقع.
- `images/`: رسومات SVG محلية للموقع.

## التشغيل
افتح `index.html` في المتصفح.

## النشر على GitHub Pages
1. أنشئ Repository جديدًا على GitHub.
2. ارفع كل الملفات والمجلدات كما هي، ولا ترفع ملف ZIP فقط.
3. من Settings ثم Pages، اختر النشر من `Deploy from a branch`.
4. اختر الفرع `main` والمجلد `/ (root)` ثم Save.

ملاحظة: نموذج الحجز تجريبي ويعرض رسالة فقط؛ لا يرسل البيانات إلى بريد إلكتروني حتى يتم ربطه بخدمة نماذج أو Backend.
